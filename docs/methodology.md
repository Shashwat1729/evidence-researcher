# Methodology

How the researcher works, and the rules it refuses to break.

1. **Search result ≠ evidence.** Every source passes classification (tier 1–7),
   fetching (verified vs metadata-only vs unavailable), and claim-linking before
   it can support anything.
2. **Never rank by domain alone.** `.edu` blogs stay tier 6; Wikipedia is tier 6
   discovery; Reddit is tier 7 leads; a commercial page hosting a dataset can be
   tier 1. Discovery value and evidentiary value are tracked separately.
3. **Claims, not vibes.** Findings are atomic claims with states
   (strongly-supported … contradicted, unknown) and per-claim confidence rationales.
   Mentions don't equal support; quality + independence do.
4. **Contradiction engine.** Each major claim triggers falsification searches
   ("evidence against …", "scholars reject …"). Stance modes (lean/adversarial/
   steelman/comparative) change the objective, never the truth conditions, and the
   stance is disclosed in the report.
5. **Provenance.** Shared-quote detection + model verdicts produce `derived_from`
   relations; the report says "N pages repeat one source" or honestly
   "independence could not be determined".
6. **Books & papers are discoveries until inspected.** Metadata (Open Library,
   Google Books, OpenAlex, Crossref, arXiv) never counts as "read". Paywalled =
   "full text unavailable".
7. **No fake citations.** Every `cite` id is checked against retrieved sources;
   page numbers/DOIs/quotes are never invented ("Page number not verified").
8. **Failure honesty.** Searched vs found vs verified vs uncertain are separate
   sections; insufficient evidence is stated, not papered over.
